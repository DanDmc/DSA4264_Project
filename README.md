DSA4264 – Course–Job Alignment Analysis

This project evaluates how well university courses align with labour market demand using NLP techniques. We process MyCareersFuture job advertisements and university course descriptions to compute semantic similarity and conduct NLP-enhanced analysis. 

## Project Structure
data/
  raw/         # Original datasets (DO NOT modify)
  processed/   # Cleaned datasets generated by scripts
src/
  data_processing/   # Scripts for cleaning and standardizing data
notebooks/     # Experimental analysis
requirements.txt


## Setup Instructions (Windows – CMD)

From the project root:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Processing Data Insturctions
To process a single job file:
python src\data_processing\process_jobs.py --input data\raw\jobs\<filename>.json
